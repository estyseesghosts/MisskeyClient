## Main rules

1. **Use approved words.**

   * Use the Simplified Technical English dictionary if you know it.
   * Use technical nouns when necessary.
   * Give one word one meaning.
   * Do not change terms only to avoid repetition. 

2. **Use active voice.**

   * Write: `The application saves the file.`
   * Do not write: `The file is saved by the application.`
   * Passive voice is permitted in descriptions when the agent is unknown. 

3. **Use short sentences.**

   * Procedure: maximum **20 words**.
   * Description: maximum **25 words**. 

4. **Give one instruction in each sentence.**

   * Bad: `Open Settings and select Accounts and remove the account.`
   * Better:
     `Open Settings.`
     `Select Accounts.`
     `Remove the account.`

5. **Use simple verb forms.**

   * Prefer simple present: `The server sends the response.`
   * For instructions, use commands: `Select the file.`
   * Avoid unnecessarily complex verb forms.

6. **Do not omit necessary words.**

   * Bad: `Files not matching rule are ignored.`
   * Better: `The application ignores files that do not match the rule.`

7. **Do not use contractions.**

   * `do not`, not `don't`
   * `cannot`, not `can't`

8. **Use one name for one thing.**

   * Do not call the same item `server`, `host`, and `machine`.
   * Select one correct term and use it consistently.

9. **Avoid long noun groups.**

   * Bad: `user authentication token refresh failure handler`
   * Better: `the handler for authentication token refresh failures`

10. **Use lists for complex information.**

    * Do not put many conditions or steps into one sentence.

11. **Keep paragraphs short.**

    * One topic in each paragraph.
    * Maximum six sentences in a paragraph. ([Skybrary][3])

12. **Use American English spelling for consistency**

## A useful writing process

Write the technical facts first. Then check each sentence:

* Is there only one main idea?
* Is the sentence 20 or 25 words or fewer?
* Is the subject clear?
* Does the subject do the action?
* Can you replace a complex word with a simple word?
* Did you use the same term for the same thing?
* Can you divide the sentence into two sentences?

For software documentation, these rules usually give a good approximation: **subject + simple verb + object, one action at a time**.
