# Palustris

An Android 13+ Jetpack Compose fediverse client for Misskey-family servers and Mastodon, inspired by Moshidon but built from scratch with a shared protocol-neutral domain and UI.

The current foundation includes protocol-detecting browser authentication, encrypted account-scoped sessions, multiple-account switching, capability-aware timelines, pagination, threads, publishing, notifications, and Misskey/Mastodon adapter coverage.

The navigation polish, richer post actions, device/browser callbacks, and authenticated-server behavior still need dedicated integration and runtime validation. Unsupported server operations remain unavailable rather than being presented as working features.
